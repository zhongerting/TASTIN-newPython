## 3. 开式回路建模

开式回路拓扑：

```text
inlet_boundary
  -> inlet_buffer
  -> MacroFlowJunction x3
  -> hot_leg_single x3
  -> inlet_mix_node x3
  -> A1..A6 segmented collector ring
  -> outlet_mix_node x3
  -> manifold_single x3
  -> MacroFlowJunction x3
  -> outlet_buffer
  -> outlet_boundary
```

建模要点：

- 使用一个显式集流环代表两个对称集流环。
- 总物理流量 `W_TOTAL=1.3 kg/s`。
- 显式单环流量约 `0.65 kg/s`。
- `MacroFlowJunction(multiplier=2)` 只用于宏观总管和单环支路之间的质量/能量倍率。
- 开式入口边界给定流量和入口温度，出口边界给定压力。
- 入口/出口混合节点不带热管，只负责支管和集流环的连接混合。

## 4. 闭式回路建模

闭式回路拓扑：

```text
Pressurizer
  -> PumpJunction
  -> HeaterChannel
  -> InletBuffer
  -> HotLeg_1/2/3
  -> InletMix_I1/I2/I3
  -> A1..A6 segmented collector ring
  -> OutletMix_O1/O2/O3
  -> Manifold_1/2/3
  -> OutletBuffer
  -> ReturnChannel
  -> Pressurizer
```

闭式回路相对开式回路的变化：

- 删除 `inlet_boundary`、`outlet_boundary` 和强制流量 `InletJunction`。
- 新增 `PressurizerVolume` 作为唯一压力参考点。
- 新增 `PumpJunction` 作为主泵，默认压升 `2070 Pa`。
- 新增 `HeaterChannel`，默认加热功率 `98 kW`。
- 新增 `ReturnChannel`，把出口缓冲体接回稳压器。
- 保留开式回路的 6 段 RingHP、局部阻力、热管求解器和辐射设置。

闭式回路默认初始化：

- 流体初始温度采用开式准稳态型分布：
  - 加热器入口、回流侧、出口侧：`756.5366 K`
  - 加热器出口、集流环入口侧：`843 K`
- 固体热状态从开式准稳态 restart 迁移：

```text
CoolantLoop/collector_ring_6segment_geometry100hp_potassium_mixed_local_loss_630s_from510s_restart.npz
```

迁移内容：

- 6 个集流环壁面固体。
- 18 个代表热管内部固体。
- 不迁移开式水力网络，因为闭式拓扑不同。

## 10. 局部阻力设置

| 连接 | 固定 `K` | 说明 |
| --- | ---: | --- |
| `Pump -> Heater` | `0.0` | 闭式新增 |
| `Heater -> InletBuffer` | `0.2` | 闭式新增 |
| `InletBuffer -> HotLeg` | `1.5` | 宏观总管到单环支路 |
| `HotLeg -> InletMix` | `1.0` | 进口支管到进口混合体 |
| `InletMix -> RingSegment` | `0.5` | 进口混合体到集流环段 |
| `RingSegment -> OutletMix` | `0.7` | 另叠加 `RingHP.outlet_dynamic_loss_params` 热管管束动态阻力 |
| `OutletMix -> Manifold` | `1.0` | 出口混合体到出口支管 |
| `Manifold -> OutletBuffer` | `1.1` | 单环出口支管到宏观总管 |
| `OutletBuffer -> Return` | `0.2` | 闭式新增 |
| `Return -> Pressurizer` | `0.2` | 闭式新增 |

热管管束压降：

- 集流环内部节点间继续使用 `inline_tube_bank_euler` 动态阻力。
- `RingSegment -> OutletMix` 保留末节点热管管束动态阻力，并额外叠加出口混合局部阻力 `K=0.7`。
- 不要把固定 `K=0.7` 当成热管管束压降的替代项。

## 11. 闭式回路泵和加热器

闭式回路默认泵压升：

```text
DEFAULT_PUMP_DELTA_P = 2070 Pa
```

来源：

- 开式局部阻力后路径压降约 `1.622 kPa`。
- 闭式新增回流管、加热管和连接损失。
- `Q_HEATER=0` 泵压升扫描：
  - `2000 Pa -> W_total_loop ≈ 1.276 kg/s`
  - `2200 Pa -> W_total_loop ≈ 1.344 kg/s`
- 插值得到 `2070 Pa` 附近可达到约 `1.3 kg/s`。

闭式回路默认加热功率：

```text
DEFAULT_HEATER_POWER = 98 kW
```

来源：

```text
Q ≈ 1.3 kg/s * (h(843 K) - h(756.54 K)) ≈ 97.98 kW
```

加热器实现方式：

- 在 `HeaterChannel` 流体控制体上施加持久热源。
- 通过 `SystemManager.add_persistent_fluid_source()` 注册。
- 每个加热器流体节点平均分配 `Q_HEATER / N_HEATER`。

## 12. V9 堆芯侧开式外管路骨架

`testModule/test_core_assemble_v9_caseA.py` 新增了一个不包含集流环和热管的堆芯侧开式外管路骨架，用于后续与本文件中的 6 段集流环三进三出接口融合前的调试。V9 不修改 V8 默认算例；它复用 V8 堆芯、TEC、NaK78 工质和导线电阻，然后重建水力网络。

V9 拓扑方向为：

```text
fixed-flow inlet
  -> V9_InletConnector
  -> #38 + #44/#50 representative branch
  -> #53 radiator inner header
  -> #52 radiator outer header
  -> cold return branches
  -> CoreInletConnector
  -> V8/V9 core representative channels
  -> CoreOutletConnector
  -> three hot outlet branches
  -> fixed-pressure outlet
```

与本文件中的集流环开式算例相比，接口语义相反：

- 集流环开式算例的入口是堆芯出口热流体进入集流环的一侧，默认温度口径约 `843 K`。
- V9 的入口是未来集流环出口侧、也就是返回堆芯前的冷侧，默认先使用 `743 K`。
- V9 的出口是未来集流环入口侧，后续应连接到集流环 `I1/I2/I3` 三个入口混合节点。

V9 第一版约束：

- 不含 `RingHP`、热管、翅片或辐射散热。
- 不加泵、不加稳压器；入口固定总质量流量，出口固定压力。
- 不使用集流环局部阻力系数，所有新增外管路局部 `K=0.0`。
- #38 单独建模，#44/#50 用 `multiplier=2` 代表；冷回流 #2/#3 用 `multiplier=2` 代表；三条堆芯出口热支路显式保留。
- 冷态水力/拓扑 smoke 使用 `run_v9_caseA_open_loop.py --disable-tec-coupled`；带 TEC 的 V9 计算应从 V9 兼容的温热 restart 或后续专用迁移器开始。

未来与 6 段集流环连接时，必须保留“两套对称集流环、只显式建一套”的倍率口径：

- V9 的 `HotOutletBranch_1/2/3` 是宏观总系统支路，每条约 `0.433 kg/s`。
- 当前集流环算例显式建模单个集流环，因此进入单环 `I1/I2/I3` 的流量应约为 `0.2167 kg/s`。
- `HotOutletBranch_1/2/3 -> InletMix_I1/I2/I3` 之间需要宏观到单环的 `MacroFlowJunction(multiplier=2)` 或等价连接。
- `OutletMix_O1/O2/O3 -> V9 冷侧外管路` 也需要单环到宏观管路的匹配 `MacroFlowJunction(multiplier=2)`。
- 不得把三条热出口支路直接硬接到单个显式集流环的 `I1/I2/I3`，否则质量流量和能量会放大错误。

## 13. 重要注意事项

1. 闭式回路不能直接加载开式全局 restart，因为水力拓扑不同。
2. 闭式回路默认只从开式 restart 迁移固体热状态，不迁移开式流体网络。
3. 若修改 `MacroFlowJunction(multiplier=2)`，必须重新核对总流量、单环流量和能量统计口径。
4. 若修改热管数量分配，必须同时核对换热面积、热管管束压降和热源/散热统计。
5. 若继续调闭式稳态温度，优先微调 `Q_HEATER` 或泵压升；不要先改热管辐射/换热模型。
6. 若新增真实回流管、加热管或三通局部阻力，应重新做泵压升扫描。
7. `Q_reject_est` 当前主要按流体焓差估算；详细能量闭合仍应结合储能项和热管/辐射诊断。
