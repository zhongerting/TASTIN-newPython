> 问题背景：总流量守恒，但 78 根辐射管之间的流量分配远大于文献计算结果的不均匀程度

## 2. 对异常形态的初步判断

当前流量分布表现为：

- 管 1 和管 40 附近流量最大；
- 管 20 和管 59 附近流量最小；
- 分布呈约 39 根管为一个周期的双峰—双谷结构；
- 总流量仍严格等于 1.3 kg/s。

这说明：

1. 双入口、双出口、78 根支管的总体拓扑大概率已经形成；
2. 入口附近流量大、远离入口处流量小的空间规律是合理的；
3. 真正异常的是流量分布幅值，而不是基本形状；
4. 模型中集流环周向压差相对于单根辐射管支路阻力明显过大。

因此，问题最可能属于：

\[
\frac{R_\mathrm{header}}{R_\mathrm{tube}}
\]

被计算得过大，其中 \(R_\mathrm{header}\) 为集流环阻力，\(R_\mathrm{tube}\) 为单根辐射管支路阻力。

# 3. 最可能的问题及优先级

## 3.1 第一优先级：集流环单段长度使用错误

这是最值得首先检查的问题。

上下集流环被 78 根辐射管划分成 78 个环向管段。相邻两根辐射管之间的集流环管段长度应为：

\[
\Delta L_u=\frac{\pi D_u}{78}
\]

\[
\Delta L_l=\frac{\pi D_l}{78}
\]

取：

\[
D_u=0.824\ \mathrm{m}
\]

\[
D_l=1.346\ \mathrm{m}
\]

得到：

\[
\Delta L_u
=
\frac{\pi\times0.824}{78}
=
0.03319\ \mathrm{m}
\]

\[
\Delta L_l
=
\frac{\pi\times1.346}{78}
=
0.05421\ \mathrm{m}
\]

正确的程序实现应接近：

```python
upper_header_segment_length = math.pi * 0.824 / 78
lower_header_segment_length = math.pi * 1.346 / 78
```

需要检查是否误写为：

```python
upper_header_segment_length = 0.824
lower_header_segment_length = 1.346
```

若将 0.824 m 和 1.346 m 直接作为每一个环向管段长度，集流环沿程压降将被放大约：

\[
\frac{0.824}{0.03319}\approx24.8
\]

\[
\frac{1.346}{0.05421}\approx24.8
\]

这足以将原本约 17% 的流量极差放大到数倍。

### 核查要点

- 参数 0.824 m 与 1.346 m 是集流环中心线直径；
- 不是相邻辐射管之间的弧长；
- 完整圆周长度应分别为：

\[
L_u=\pi\times0.824=2.5887\ \mathrm{m}
\]

\[
L_l=\pi\times1.346=4.2286\ \mathrm{m}
\]

- 每段长度等于完整圆周长度除以 78。

---

## 3.2 第一优先级：上下集流环方向和压降符号错误

原始详细模型对上下集流环采用不同的正方向：

- 上集流环顺时针为正；
- 下集流环逆时针为正。

这是因为相邻两根辐射管与对应的上下集流环段组成闭合水力回路。

相邻两根辐射管的闭环压降平衡可概括为：

\[
\Delta P_{T,i}
+\Delta P_{L,i}
-\Delta P_{T,i+1}
-\Delta P_{U,i}
=0
\]

其中：

- \(\Delta P_{T,i}\)：第 \(i\) 根辐射管压降；
- \(\Delta P_{U,i}\)：上集流环第 \(i\) 段压降；
- \(\Delta P_{L,i}\)：下集流环第 \(i\) 段压降。

若代码中上下集流环都定义为：

```python
edge_i: node[i] -> node[i + 1]
```

但在闭环残差中没有相应调整符号，可能导致上下集流环压差错误叠加。

### 可能的错误表现

- 入口附近支管驱动压差异常大；
- 远端支管驱动压差显著偏低；
- 最大流量远大于平均值；
- 仍能保持总质量守恒；
- 分布形状正确，但幅值严重失真。

### 推荐打印量

对管 1、20、40、59 输出：

| 管号 | 上集流环压力 | 下集流环压力 | 支管驱动压差 | 支管压降 | 流量 |
|---:|---:|---:|---:|---:|---:|
| 1 |  |  |  |  |  |
| 20 |  |  |  |  |  |
| 40 |  |  |  |  |  |
| 59 |  |  |  |  |  |

定义：

\[
\Delta P_{\mathrm{drive},i}
=
P_{u,i}-P_{l,i}
\]

若不同管位的 \(\Delta P_{\mathrm{drive}}\) 相差数倍，问题应沿上下集流环压力分布继续追查。

---

## 3.3 第一优先级：集流环阻力相对于辐射管阻力过大

当前结果说明支管流量对集流环位置极其敏感。这通常意味着：

- 集流环压降过大；
- 辐射管支路阻力过小；
- 或两者同时存在。

用水力阻力形式表示：

\[
\Delta P=R\dot m|\dot m|
\]

如果：

\[
R_\mathrm{header}\gg R_\mathrm{tube}
\]

则入口附近上下联箱之间的压差会显著高于远端，导致入口附近支管产生过大流量。

文献中最大与最小单管流量仅相差约 17%～18%，说明真实模型中单根辐射管支路阻力应占据重要地位，集流环造成的节点压差变化相对有限。

---

## 3.4 第二优先级：辐射管长度、内径或沿程阻力实现错误

单根辐射管的基本参数应为：

| 参数 | 推荐值 |
|---|---:|
| 管长 | 约 1.85 m |
| 外径 | 8 mm |
| 内径 | 7 mm |
| 壁厚 | 0.5 mm |
| 平均流量 | 0.01667 kg/s |

需要检查：

1. 管长是否使用 1.85 m；
2. 是否误用 1.83 mm、0.185 m 或离散单元长度；
3. 是否使用内径 7 mm 计算流通面积；
4. 是否错误使用外径 8 mm；
5. 是否遗漏沿程摩擦；
6. 是否只计算了入口和出口局部阻力；
7. 是否在辐射管压降中遗漏重力项或加速度项，但又在集流环中保留；
8. 是否所有 78 根支管参数完全一致。

正确的辐射管压降形式应至少包括：

\[
\Delta P_\mathrm{tube}
=
f_D\frac{L}{D}
\frac{\rho v^2}{2}
+
K_\mathrm{local}
\frac{\rho v^2}{2}
\]

其中：

\[
v=\frac{\dot m}{\rho A}
\]

\[
A=\frac{\pi D^2}{4}
\]

---

## 3.5 第二优先级：局部阻力系数不足

当前模型中若采用：

```python
tube_inlet_k_loss = 2.0
tube_outlet_k_loss = 2.0
```

则总局部阻力系数为：

\[
K_\mathrm{local}=4
\]

该值未必错误，但应确认真实结构是否还包含：

- 集流环至细管的突然收缩；
- 焊接接头；
- 管口倒角；
- 入口分配结构；
- 出口突然扩张；
- 局部弯曲或安装偏差；
- 等效节流结构。

支管局部阻力越大，各支管流量对集流环节点压力差的敏感性越低，流量分布越均匀。

但不建议直接把 \(K\) 调大到匹配文献，而应先排除集流环长度、摩擦因子和单位错误。

---

## 3.6 第二优先级：Darcy 与 Fanning 摩擦因子混用

Darcy–Weisbach 形式：

\[
\Delta P
=
f_D\frac{L}{D}
\frac{\rho v^2}{2}
\]

Fanning 形式：

\[
\Delta P
=
4f_F\frac{L}{D}
\frac{\rho v^2}{2}
\]

两者满足：

\[
f_D=4f_F
\]

常见错误包括：

- 相关式输出 Fanning 因子，却按 Darcy 因子直接使用；
- 上下集流环使用 Darcy 因子；
- 辐射管使用 Fanning 因子；
- 某处又额外乘以 4；
- 层流和湍流分支采用了不同定义。

如果只把集流环压降放大 4 倍，而辐射管未同步放大，流量不均匀性会显著增大。

建议统一规定：

```text
所有支路均使用 Darcy friction factor
```

并对每个压降函数注明摩擦因子定义。

---

## 3.7 第二优先级：质量流量与流速换算错误

正确关系：

\[
v=\frac{\dot m}{\rho A}
\]

常见错误：

```python
velocity = mass_flow_rate / area
```

正确应为：

```python
velocity = mass_flow_rate / (density * area)
```

还需检查：

- \(\dot m\) 是否统一使用 kg/s；
- 密度是否使用 kg/m³；
- 体积流量是否使用 m³/s；
- 管径是否统一使用 m；
- 压降是否统一使用 Pa；
- 是否在部分函数中使用 g/cm³ 或 cm²；
- 是否对 NaK 密度做了重复换算。

由于压降与速度平方近似成正比，任何单位错误都会被放大。

---

## 3.8 第二优先级：4.245 压降修正系数使用位置错误

文献中的 4.245 是针对完整系统回路压降的经验修正系数，用于补偿没有显式建模的局部阻力，如：

- 弯头；
- 扩缩口；
- 接头；
- 未建模构件；
- 复杂局部结构。

它不是专用于辐射器集流环的修正系数。

若代码中执行：

```python
dp_upper_header *= 4.245
dp_lower_header *= 4.245
```

而辐射管压降没有采用相应处理，就会人为放大集流环阻力，导致流量分布过度不均匀。

建议：

1. 辐射器流量分配单元测试中暂时关闭 4.245；
2. 先用纯几何压降模型检查流量分布；
3. 仅在完整系统泵扬程—总流量闭合时使用该修正系数；
4. 或将其分配到实际缺失的局部构件，而不是集中施加在集流环上。

---

## 3.9 第三优先级：完整闭合环实现产生非物理环流

上下集流环是闭合环形管道，但在双入口、双出口和完全对称工况下，应满足明确的分流和汇流规律。

理论上：

- 每个入口承担约 0.65 kg/s；
- 每个入口向两个方向各分约 0.325 kg/s；
- 上集流环流量由入口向两个入口之间的中点逐渐减小至接近零；
- 下集流环流量由中点向出口逐渐增大至约 0.325 kg/s。

若模型出现以下现象，则可能存在非物理环流：

- 某些集流环段流量超过 0.325 kg/s；
- 一个入口向另一个入口输送明显流量；
- 环向流量在无源节点处突变；
- 上集流环流量不单调；
- 下集流环流量不单调；
- 存在与对称工况无关的持续环流；
- 周期边界重复连接或漏连。

需要检查：

```text
UH[78] ↔ UH[1]
LH[78] ↔ LH[1]
```

是否只连接一次，以及入口/出口节点是否因为图网络构造被重复添加。

---

## 3.10 第三优先级：入口和出口方位问题

当前模型可能采用：

```python
inlet_idx_a = 0
inlet_idx_b = 39

outlet_idx_a = 0
outlet_idx_b = 39
```

这种布置会使管 1 和管 40 同时靠近上部入口和下部出口，因此形成较短的水力路径。

但从公开详细模型的编号和守恒方程看，上部入口和下部出口大概率确实位于相同的两个周向分界位置，即约 0° 和 180°。

因此：

> 出口相对入口错开 90°可以作为敏感性分析，但不应作为第一修正手段。

例如：

```python
outlet_idx_a = 19
outlet_idx_b = 58
```

可能明显压平流量分布，但这相当于修改了原始几何拓扑。

只有在前述长度、方向、阻力、摩擦因子和单位问题全部排除后，才建议系统研究接口错位角度。

# 4. 推荐的诊断算例

## 4.1 Case A：集流环零阻力测试

设置：

```python
upper_header_friction_factor = 0.0
lower_header_friction_factor = 0.0
upper_header_local_k = 0.0
lower_header_local_k = 0.0
```

理论预期：

\[
\dot m_i=\frac{1.3}{78}
=0.0166667\ \mathrm{kg/s}
\]

所有支管流量应相同。

### 判断

- 若完全均匀：拓扑和支管参数基本一致，问题在集流环压降；
- 若仍不均匀：拓扑、边界条件或支管参数存在错误；
- 若部分管流量为负：方向、节点连接或压力边界存在严重错误。

---

## 4.2 Case B：常数二次支管阻力测试

将每根辐射管替换为完全相同的简化阻力：

\[
\Delta P_i
=
K_t\dot m_i|\dot m_i|
\]

不使用温度相关物性，也不使用复杂摩擦因子。

目的：

- 排除 NaK 物性函数；
- 排除雷诺数分支；
- 排除热模型；
- 只检查网络拓扑和压力分配。

如果此时仍出现最大/最小约 4 倍，说明问题一定在集流环或网络拓扑。

---

## 4.3 Case C：辐射管阻力倍增扫描

保持集流环模型不变，将所有辐射管阻力统一乘以：

\[
1,\ 2,\ 5,\ 10,\ 20
\]

记录：

| 倍数 | 最小流量 | 最大流量 | 极差/平均值 |
|---:|---:|---:|---:|
| 1 |  |  |  |
| 2 |  |  |  |
| 5 |  |  |  |
| 10 |  |  |  |
| 20 |  |  |  |

若阻力乘数约 10 时，流量范围从：

\[
0.00946\sim0.03804\ \mathrm{kg/s}
\]

收缩到：

\[
0.0158\sim0.0188\ \mathrm{kg/s}
\]

则说明集流环阻力与支管阻力的相对比例错误。

这不是最终修正方案，而是定位手段。

---

## 4.4 Case D：集流环内径扫描

分别测试：

\[
D_h=20,\ 22,\ 24,\ 26,\ 30\ \mathrm{mm}
\]

集流环压降对内径非常敏感，近似满足：

\]

因此，从 20 mm 增加到 22 mm，压降可能显著下降。

记录：

| 集流环内径 | 最小流量 | 最大流量 | 极差/平均值 |
|---:|---:|---:|---:|
| 20 mm |  |  |  |
| 22 mm |  |  |  |
| 24 mm |  |  |  |
| 26 mm |  |  |  |
| 30 mm |  |  |  |

若 20 mm 与 22 mm 之间变化极大，说明模型对集流环水力直径高度敏感，需要明确几何内径与 TITAM 有效内径的口径。

## 4.5 Case E：压降预算输出

对代表性管位打印完整压降分解：

| 项目 | 管 1 | 管 20 | 管 40 | 管 59 |
|---|---:|---:|---:|---:|
| 上集流环节点压力 |  |  |  |  |
| 下集流环节点压力 |  |  |  |  |

| 支管沿程压降 |  |  |  |  |
| 支管入口局部压降 |  |  |  |  |
| 支管出口局部压降 |  |  |  |  |
| 支管重力压降 |  |  |  |  |
| 支管总压降 |  |  |  |  |

P_{u,i}-P_{l,i}

## 4.6 Case F：集流环流量曲线检查

正确趋势应为：

### 上集流环

\[
0.325\ \mathrm{kg/s}
\rightarrow
0
\]

即从入口向相邻两个入口之间的中点逐步减小。

### 下集流环

\[
0
\rightarrow
0.325\ \mathrm{kg/s}
\]

即从中点向出口逐步增加。

应检查：

- 是否单调；
- 是否对称；
- 是否出现超过 0.325 kg/s 的流量；
- 是否出现无物理原因的方向反转；
- 是否存在入口之间的贯穿流。

## 4.7 Case G：接口错位敏感性测试

仅作为最后的结构敏感性分析。

测试：

```python
outlet_idx = [0, 39]
outlet_idx = [10, 49]
outlet_idx = [19, 58]
```

对应出口相对入口错位：

\[
0^\circ,\quad约46^\circ,\quad约88^\circ

如果只有出口错位后才能匹配文献，而原拓扑下无论如何都无法匹配，则需要重新核对原始装配图或详细模型边界方程。

# 5. 建议的排查顺序

## 步骤 1：检查集流环单段长度

确认：

```text
upper segment length = 0.03319 m
lower segment length = 0.05421 m
```

而不是：

```text
0.824 m
1.346 m
```

## 步骤 2：执行集流环零阻力测试

期望：

\[
\dot m_i=0.01667\ \mathrm{kg/s}
\]

## 步骤 3：检查上下集流环方向和闭环符号

重点核对下集流环方向和压降项符号。

## 步骤 4：输出四根代表性支管的压力预算

选择：

```text
tube 1
tube 20
tube 40
tube 59
```

## 步骤 5：检查摩擦因子定义

统一使用 Darcy 摩擦因子。

## 步骤 6：检查辐射管参数

确认：

```text
L = 1.85 m
ID = 0.007 m
```

## 步骤 7：关闭 4.245 系统修正系数

# 8. 最终判断

目前最可能的问题依次为：

1. **集流环每段长度取错**；
2. **上下集流环方向或闭环压降符号错误**；
3. **集流环阻力相对于辐射管阻力过大**；
4. **辐射管长度、内径或沿程阻力实现错误**；
5. **Darcy/Fanning 摩擦因子混用**；
6. **质量流量、密度、截面积或单位换算错误**；
7. **4.245 系统压降修正系数错误施加于集流环**；
8. **完整闭合环产生非物理环流**；
9. **入口/出口方位与原模型不一致**。

综合当前分布形态，最符合现象的判断是：

> 双入口双出口拓扑总体正确，但集流环周向压力变化被放大，导致入口附近支管获得过高的驱动压差。应首先检查上、下集流环每段长度是否分别为 33.19 mm 和 54.21 mm，然后检查下集流环方向、闭环压降符号以及 4.245 修正系数的使用位置。

在这些问题排除之前，不建议通过人为改变出口角度或大幅增加局部阻力系数来拟合文献流量范围。
