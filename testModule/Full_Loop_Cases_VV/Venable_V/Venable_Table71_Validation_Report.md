# Venable Table 7-1 单 TFE 最大输出功率验证计算报告

## 1. 报告目的

本文记录 `Venable_V` 当前阶段对 Venable 1995 单电池 TFE 电特性试验 Table 7-1 的验证计算结果。

验证目标是文献给出的 14 个 active-zone power 工况下的最大输出功率和效率。计算侧使用 ThermoCalc 单 TFE 电输出模型，通过固定端电压扫描提取最大输出功率，并与 Venable Table 7-1 数据对比。

当前报告对应最终保留的诊断 run：

```text
20260702_035000_tisa300_profile_peak55_scan41
```

结果目录：

```text
testModule/Full_Loop_Cases_VV/Venable_V/runs/20260702_035000_tisa300_profile_peak55_scan41
```

## 2. 文献数据和严格约束

本次验证严格保持以下 Venable Table 7-1 实验锚点：

- `Q_az` 使用 Table 7-1 的 active-zone power 原值，不再乘 Benke 的 0.88 修正。
- `P_out,max` 和效率只作为验证目标，不作为输入反推。
- 最优 Cs 压力按文献分段：
  - 892-1405 W：0.4 torr
  - 1580-2112 W：0.5 torr
  - 2281-2637 W：0.8 torr
  - 2813-3162 W：1.0 torr
- 最大功率由计算侧电压扫描提取，不直接指定实验最大功率。


## 6. Benke 水冷夹套和 He gap 尝试

本轮已实现 `collector_boundary_mode = benke_water_jacket`，用于显式表达资料中的水冷夹套和调压 He gap 热阻路径。

该模式包含：

- 冷却水入口或等效边界温度；
- 冷却水质量流量；
- 水比热；
- 水侧换热系数；
- 输入热量进入水冷路径的比例；
- 调压 He gap 宽度；
- 调压 He gap 等效导热系数；
- 额外 collector 热阻。

资料给出的可用范围包括：

| 参数 | 资料中可用信息 |
| --- | --- |
| 调压 He gap 宽度 | 约 0.5 mm |
| 调压 He gap 压力 | 正常运行约 1-10 torr |
| 反推有效导热系数 | 约 0.073-0.087 W/(m·K) |
| 连续介质 He 导热估算 | 约 0.276 W/(m·K) |
| 水侧换热系数 | 约 528-1012 W/(m2·K) |
| 冷却水流动状态 | Re 约 1480，过渡/层流附近 |

调试结论：

1. 使用接近室温水的真实水冷边界时，collector 温度过低，最低功率点甚至出现零输出，明显不适合直接替代当前 collector 闭合。
2. 提高等效水冷边界温度或增大等效热阻后，低中功率可以贴近实验，但高功率段容易过预测。
3. 目前公开整理资料没有给出 Venable Table 7-1 各电工况的套筒温度、水入口/出口温度、水流量和调压 He gap 实际状态，因此 water/He 模型虽然结构上更物理，但约束不足。
4. 当前不建议用不真实的高水温或逐点 He gap 热阻去强行压误差。

因此，本报告保留 `benke_water_jacket` 作为后续热边界模型入口，但当前最佳电输出验证结果仍使用经验型 `collector_boundary_mode = linear`。

## 7. 误差特征分析

当前误差主要集中在两个区间：

- 1237-1580 W：计算偏低，最大低估出现在 1405 W，约 -15.7%。
- 2281-2474 W：计算偏高，最大高估出现在 2474 W，约 +10.9%。

这说明当前全局温度闭合已经能描述总体趋势，但仍不能完全复现实验中的中低功率到中高功率过渡区。可能原因包括：

- 真实 TISA 轴向温度分布不是当前简化的分段三角/平台形状；
- collector 温度并非简单线性随 `Q_az` 增长；
- 调压 He gap、非调压 He gap、套筒、水冷夹套之间的热阻随功率或装配状态变化；
- 表面功函数、Cs 覆盖状态或发射模型参数与当前 ThermoCalc 默认值存在差异；
- Venable Table 7-1 最大功率点来自实验 I-V 曲线，局部电压扫描分辨率和模型电路定义仍可能存在细节差异。

## 8. 当前结论

当前 `Venable_V` 已完成一套可复现的 14 点 ThermoCalc 验证计算。相较早期 baseline，模型已完成以下改进：

- 固定文献 `Q_az`、`P_out,max`、效率和最优 Cs 压力分段；
- 使用源依据几何尺寸推导面积；
- 使用 ThermoCalc 生产公式完成 `Pcs -> Tcs` 映射；
- 将轴向热释放分布改为 300 mm TISA 加热段；
- 实现并测试 Benke water-jacket / He gap collector 边界；
- 完成多轮全局参数诊断并留痕。

当前最佳结果：

```text
平均绝对相对误差：6.64%
最大绝对相对误差：15.66%
最大绝对功率误差：14.11 W
```

该结果可作为 Venable Table 7-1 单 TFE 电输出的半定量验证结果。它不是完全源依据的预测型 V&V，因为 emitter/collector 均温闭合仍含经验调节。

## 9. 后续建议

后续若继续提高可信度，优先顺序应为：

1. 数字化 Benke/Venable 轴向套筒温度或 TFE 温度图，替代当前经验轴向温度幅度。
2. 获取或反推 Venable Table 7-1 各工况的水冷边界，包括水入口/出口温度、流量、套筒温度。
3. 用 Benke 热阻网络重新生成 collector 温度，而不是直接拟合 collector mean。
4. 在热边界充分约束后，再考虑全局表面参数或发射模型参数敏感性。
5. 避免逐工况调节 He gap、功函数或温度缩放，否则结果会失去预测性。
