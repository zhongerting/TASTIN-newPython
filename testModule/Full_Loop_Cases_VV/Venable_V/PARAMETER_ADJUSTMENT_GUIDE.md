# Venable Table 7-1 参数调整边界说明

本文用于约束后续 Venable 单 TFE 最大输出功率验证中的参数调整。目标不是提前保证一定能完全复现实验，而是在验证偏差较大时明确：哪些量必须严格对应文献，哪些量可以在有依据、有记录的前提下调整。

适用范围仅限 `Venable_V` 下的 Venable 1995 单电池 TFE 电特性试验 Table 7-1 最大输出功率工况。

## 当前验证对象

当前目标是 Venable 1995 单电池 TFE 电输出实验的 Table 7-1 最大输出功率数据。

当前文件分工：

- `venable_table71_data.py`：固化 Table 7-1 的实验锚点。
- `venable_single_tfe_model.py`：把工况抽象为后续 ThermoCalc 可接收的单 TFE 输入。
- `cases_table71.csv`：已生成的 14 个工况摘要。
- `model_config_summary.json`：当前几何和 placeholder 热闭合摘要。

该验证对象不是 V-71 全回路，不是 V12/V13 工况，也不直接包含点堆动力学、辐射器、泵、系统压力或完整回路效应。

## 必须严格对应的量

这些量属于实验数据或定义层约束，不能为了改善计算结果而修改。

| 项目 | 必须保持的处理 | 原因 |
| --- | --- | --- |
| 工况类型 | 单电池 TFE 电特性试验 | Venable 数据源不是 TOPAZ-II 全系统回路试验。 |
| Table 7-1 的 `Q_az` | 14 个 active-zone power 必须原样使用：892 到 3162 W | 这是每个工况的独立热输入。 |
| `Q_az` 口径 | Table 7-1 的 active-zone power 已是有效工作段热输入，不能再乘 Benke 的 0.88 | 重复修正会把热输入系统性压低。 |
| 实验最大输出功率 | 14 个 `P_out,max` 只能作为验证目标，不能作为模型输入 | 输出量不能反向喂给模型。 |
| 实验效率 | 按文献值保留；只允许用 `100*P_out/Q_az` 做四舍五入一致性检查 | 效率是报告结果，不是调参变量。 |
| 最优 Cs 压力分段 | 892-1405 W 用 0.4 torr；1580-2112 W 用 0.5 torr；2281-2637 W 用 0.8 torr；2813-3162 W 用 1.0 torr | Table 7-1 是最优铯压下的最大功率点。 |
| 最大功率定义 | 计算侧必须通过负载扫描、I-V 曲线扫描或优化得到最大功率 | 不能直接指定实验最大功率。 |
| 单位 | W、%、torr、K、m、m2 等单位必须与当前文件和文献口径一致 | 单位错误会伪装成物理模型偏差。 |
| 误差符号 | 相对误差建议统一为 `(calc - exp) / exp` | 保证后续对比表可读、可累积。 |

## 有文献确认后也应锁定的量

这些量当前可能还是 placeholder 或继承自现有 ThermoCalc 默认值。后续一旦从 Venable/Benke 文献或几何图中确认，就应固定下来，不再作为拟合旋钮。

| 参数 | 当前值 | 当前状态 | 后续规则 |
| --- | ---:| --- | --- |
| active length | 0.375 m | 暂定几何锚点 | 若文献确认，则固定；若发现更准确来源，只做一次源依据替换。 |
| emitter-collector gap | 0.0005 m | 暂定文献相关值 | 文献确认后固定，不用于逐点拟合。 |
| emitter/collector side area | 发射极 OD 19.6 mm、集电极 ID 20.6 mm、active length 375 mm 推导 | 已按 `TOPAZII_VV_public_experimental_data.md` 锁定 | 后续只在发现更高优先级原文几何时替换。 |
| emitter/collector cross area | 发射极厚 1.15 mm、集电极厚 1.4 mm 的环形截面积 | 已按 `TOPAZII_VV_public_experimental_data.md` 锁定 | 后续只在发现更高优先级原文几何时替换。 |
| 电极材料和表面类型 | TOPAZ-II TFE 相关材料 | 目前仍需映射到代码材料参数 | 一旦映射完成，作为全局物理设定固定。 |
| `Pcs -> Tcs` 映射 | ThermoCalc 生产压力公式 | 已由 `Pcs_torr = 2.45e8 / sqrt(Tcs) * exp(-8910 / Tcs)` 替换原 placeholder | 主验证优先固定该源依据；只有找到 Venable 储罐标定时才替换。 |

## 可以调整但必须留痕的量

这些量没有被 Table 7-1 完整说明，后续如果验证不理想，可以调整。但每次调整都必须说明来源、范围、目的和对 14 个工况误差的影响。

| 可调项 | 为什么可以调 | 优先依据 | 主要影响 |
| --- | --- | --- | --- |
| emitter 温度闭合 | Table 7-1 给的是热输入，不是逐节点发射极温度；当前最佳诊断使用全局二次峰值项 | Benke 热阻模型、TISA 加热模型、能量平衡 | 强烈影响发射电流和最大功率；拟合型二次项只能标记为 diagnostic。 |
| collector 温度闭合 | Table 7-1 没有直接给出逐节点集电极温度；当前最佳仍保留线性经验闭合 | Benke 冷却水夹套、套筒温度或热阻网络 | 影响回发射、功函数和效率；`benke_water_jacket` 已实现但因缺少逐工况边界暂不作为最佳模型。 |
| 轴向温度分布 | 已新增 `tisa_300mm`：300 mm TISA 加热段居中于 375 mm 工作段；幅度仍为诊断参数 | Benke/Venable 轴向温度图数字化或热模型输出 | 改变局部发射分布；可保留 TISA 几何形状，但幅度不能逐点拟合。 |
| `Q_az` 到电极温度的热损失分配 | 有效热输入已知，但外部散热路径未完全闭合 | 试验台热阻、保温层、He gap 和冷却边界 | 改变温度，不改变 `Q_az` 本身；已暴露 water-jacket heat pickup fraction 和 He gap 等效导热参数供诊断。 |
| 电极有效功函数/表面因子 | Cs 覆盖和表面状态可能无法完全由公开数据确定 | TOPAZ-II/TFE 文献值优先；必要时做有界全局校准 | 强烈影响 I-V 曲线高度。 |
| Richardson 常数/发射模型常数 | 代码默认值可能不完全代表试验表面 | 文献值优先，其次做敏感性分析 | 强烈影响电流密度。 |
| 外部接触/导线电阻 | 试验台端电压定义和导线细节可能不完整 | 接线说明、I-V 曲线斜率、合理电阻范围 | 影响端电压和最大功率点位置。 |
| 负载扫描分辨率/优化方法 | 这是数值搜索问题，不是实验物理参数 | 加密到最大功率不随步长变化 | 避免因扫描太粗低估峰值。 |
| 网格节点数 | 数值离散参数 | 网格无关性检查 | 只能用于收敛性，不应用来拟合实验。 |
| 求解器容差和迭代上限 | 数值稳健性参数 | 收敛性和非有限结果诊断 | 应改善稳定性，不应改变物理趋势。 |

## 只能作为敏感性分析的量

这些量可以用于判断不确定性，但不应进入主验证模型，除非后续找到明确文献依据。

| 项目 | 使用规则 |
| --- | --- |
| active length 变化 | 只能用于几何不确定性包络；不得逐功率点调整。 |
| gap 变化 | 只能在文献存在歧义时做全局敏感性分析；不得逐点调整。 |
| 面积倍率或有效发射面积因子 | 如果需要，只能作为单一全局敏感性参数；不得每个工况单独给倍率。 |
| Cs 最优压力重分配 | Table 7-1 主验证必须保留文献分段；压力重分配只能用于单独的 I-V/铯压扫描验证。 |
| 逐工况功函数拟合 | 原则上避免；若用于诊断，必须标记为 non-predictive，不得作为正式验证结果。 |

## 禁止用于强行拟合的操作

后续即使结果对不上，也不要做以下操作：

- 修改 14 个文献 `Q_az`、`P_out,max` 或 efficiency。
- 对 Venable Table 7-1 的 `Q_az` 再乘 Benke 的 0.88。
- 把实验最大输出功率直接作为边界条件或目标电流/电压输入。
- 给每个 Table 7-1 工况单独设置任意几何、任意面积倍率、任意功函数或任意温度缩放。
- 把该单 TFE 工况切换成 V-71、V12、V13 或其他全回路拓扑。
- 用点堆动力学、反应性反馈、辐射器、泵、系统压力来解释 Venable 单电池电特性偏差。
- 只报告调参后结果，不报告 baseline 和调整记录。

## 建议的调整顺序

1. 先跑当前 baseline 的 14 点最大功率计算，记录 `P_calc`、`eta_calc`、相对误差。
2. 先排除数值问题：负载扫描范围、扫描分辨率、网格无关性、求解容差、非有限结果。
3. 若发现 Venable 储罐标定，才替换当前 ThermoCalc 生产压力公式；否则固定现有 `Pcs -> Tcs` 映射。
4. 用 Benke/Venable 热阻网络、TISA 加热模型或能量平衡替换 placeholder 电极温度闭合。
5. 几何面积已按本地整理的 Benke/Venable 单电池尺寸推导；后续只在找到更高优先级原文几何时替换。
6. 只有在 2-5 完成后，才考虑有界的全局表面/发射参数校准。
7. 最终必须用同一套全局参数同时验证 14 个点，不做逐点拟合。

## 调整记录格式

后续每次调整可调参数时，建议在日志、结果说明或后续 `adjustment_log.md` 中按以下格式记录：

```text
Parameter:
Previous value:
New value:
Scope: global / case group / single diagnostic case
Source status: directly sourced / derived / sensitivity / fitted
Rationale:
Affected files:
Baseline error summary:
New error summary:
Decision: keep / reject / diagnostic only
```

只有满足以下条件的调整才应进入正式 Venable 验证模型：

- 参数是全局的，或来自明确文献/几何推导；
- 能同时改善或解释 14 个点的整体趋势；
- 不破坏 `Q_az`、`Pcs`、最大功率之间的物理单调性和最优铯压规律；
- 有 baseline 对照和调整记录。
