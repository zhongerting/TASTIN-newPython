# V14低电功率fixed-I调试计划与记录

## 1. 目标和固定约束

初态采用：

```text
V14_210kW_fixed_power_external_heat_2orbits/runs/
two_orbits_from13864_20260720/checkpoint_t019265s.npz
```

目标过程：

1. 加载初态并按当前温度刷新TEC，读取实际主回路电流 `I0` 和电功率 `Pe0`。
2. TEC从当前fixed-U无扰切换为 `fixed_I(I0)`。
3. 前20 s保持初始总热功率和总流量。
4. 随后1000 s内主要降低总热功率，并辅助降低设定总流量，使电功率从 `Pe0` 降到 `0.4*Pe0`。
5. 到达低功率状态后锁存 `Q_low` 和 `W_low`；保持阶段二者不得再调整。
6. 固定 `Q_low/W_low/I0` 计算至少一个完整外热周期 `5668.144369 s`。

低功率保持阶段的第一轮验收范围为初始电功率的35%到45%。堆芯出口冷却剂温度在整个
外热周期内不得超过初始checkpoint的出口温度。正式过程保留轨道外热、水力、流固换热、
固体导热、热管和TEC；不使用温度反应性反馈，堆芯总热功率由理想控制系统直接设定。

## 2. 必须监视的物理量

### 2.1 电学

- 固定电流目标、实际总电流、端电压和端电功率；
- 各代表性TFE电流密度、电势差、电子冷却/加热及轴向焦耳热；
- TEC收敛状态和fixed-I回退状态。

fixed-I目标不可实现时，本轮判为不可行。不得自动改为零电流开路，也不得把回退结果当作
有效的40%功率状态。

### 2.2 热工和水力

- 总热功率设定值和实际堆芯热源；
- 总设定流量、实际总流量及各支路流量；
- 堆芯进出口温度和温差；
- 燃料、发射极、接收极、内外套管、慢化剂和反射层温度；
- 集流环壁面、直热管、环形热管和辐射器温度；
- 辐射器净散热功率及外热吸收功率；
- 水力收敛状态、压力和焓。

### 2.3 热管低温能力

当前模型没有离散的热管工作温度开关。吸液芯轴向导热率由结构导热和温度相关赝热导组成，
赝热导依赖钾饱和蒸汽压、蒸汽黏度和汽化潜热。温度降低时性能是连续且强非线性退化。

每轮必须记录：

- 各类热管蒸发段、绝热段和冷凝段的最低/平均/最高温度；
- `WickMaterial.conductivity_axial(T)` 的最低/平均/最高值；
- 热管蒸发端吸热、冷凝端放热及轴向温差；
- 集流环和管翅式辐射器的净散热能力。

不得用未经当前模型定义的单一“启动温度”代替这些诊断。

## 3. 调试阶段

### 阶段A：初态审计

- 校验checkpoint及相邻run_config；
- 记录绝对时刻和外热相位；
- 刷新TEC后记录 `I0/Pe0/U0`；
- 记录 `Q0=210 kW`、`W0=2.46 kg/s`、堆芯出口温度和全部温限裕量；
- 保存不可修改的基线摘要。

通过条件：状态有限，水力和TEC收敛，外热相位与源算例连续。

### 阶段B：fixed-U到fixed-I无扰切换

- 保持 `Q0/W0` 不变，切换到 `fixed_I(I0)`；
- 先运行0.1 s smoke，再运行20到50 s保持段；
- 比较切换前后电压、电功率、TEC热源和全局能量残差。

通过条件：无明显瞬时跳变，fixed-I持续收敛，电功率偏差不超过2%。

### 阶段C：局部灵敏度辨识

短算中分别辨识热功率和流量作用，正式降功率过程仍要求二者共同下降。

- 热功率先做小扰动，优先使用-2%、-5%和-10%，避免假定热功率需降到40%；
- 流量先做-2%、-5%和-10%扰动；
- 每次保持100到300 s，记录电功率、出口温度、TEC温差和热管等效导热率响应；
- 估计 `dPe/dQ`、`dPe/dW`、`dTout/dQ`、`dTout/dW` 及主要时间常数。

### 阶段D：短程联合候选

- 根据阶段C结果选取少量独立的 `Q_end/W_end` 组合；
- 热功率是主要调节量，流量仅用于维持出口温度和热管散热能力；
- 使用200到500 s缩短斜坡筛除明显不合格组合；
- 不跑完整外热周期。

淘汰条件：TEC不收敛、出口温度上升、热管赝热导显著塌缩、水力不收敛或电功率越过目标后
继续快速下降。

### 阶段E：1000 s正式下降调试

- 使用平滑目标曲线执行1000 s下降；
- 热功率和流量采用独立变化率和独立终值；
- 电功率跟踪是热功率控制的主要目标；
- 流量根据出口温度、热管温度和散热能力缓慢调整；
- 到达40%附近后记录并锁存候选 `Q_low/W_low`。

### 阶段F：固定参数短保持

- 固定 `I0/Q_low/W_low`，先保持300到600 s；
- 确认控制量没有继续变化；
- 检查电功率是否位于35%到45%，出口温度是否低于初始值，热管性能是否仍有裕量。

### 阶段G：完整外热周期

- 从合格的低功率checkpoint继续计算5668.144369 s；
- `I0/Q_low/W_low` 全程固定；
- 报告电功率周期最小值、最大值、平均值和超出35%到45%的持续时间；
- 报告出口温度周期最大值及发生相位；
- 比较周期首尾同相位的全部关键温度，判断是否存在长期漂移。

如一个周期后同相位温度仍明显漂移，只记录结论；是否追加第二周期另行决定，不自动延长。

### Iteration 02-04：局部响应与水力控制异常

- 日期：2026-07-22。
- 统一轨迹：20 s 保持、100 s 平滑下降、200 s 低功率保持，`dt=0.05 s`。
- `Q/Q0=0.95, W/W0=1.00` 在事故经过 180 s 的完整 checkpoint 上得到 `Pe/Pe0=0.938578`；热功率对电功率的局部静态斜率约为 1.46，据此下一批固定流量端点取 `Q/Q0=0.55/0.60/0.65`。
- `W/W0=0.95` 的两轮均在 22.15 s 淘汰。目标流量仅由 2.46 降至 2.459831875 kg/s，实际流量却降至 2.046408517 kg/s，泵压头出现符号相反的大幅值。
- 根因一：`HydraulicNetwork` 原入口控制离散为 `Wnew=Wold+dt*50*(Wtarget-Wold)`；`dt=0.05 s` 时误差放大因子为 -1.5，必然交替发散。现将松弛权重限制为 `min(dt*gain, 1)`。
- 根因二：本目录公共流路曾同时把两台串联泵构造成流量控制器。现只控制 `pump_a`，`pump_b` 保持普通定压头泵，两台仍各承担总设计压头的一半；fixed-I runner 同步改为只设置和验收实际受控泵。
- 验证：水力控制、公共流路构建和低功率控制共 27 项窄测试通过。
- 决策：修复前的两个降流候选无物理意义，不用于灵敏度拟合；先以 `W/W0=1.00` 搜索热功率端点，后续仅在修复后重新评估小幅降流。
