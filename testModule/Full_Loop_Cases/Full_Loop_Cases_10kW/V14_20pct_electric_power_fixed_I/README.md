末端300 s窗口（相对时间1200-1500 s，含浮点时间容差）结果：

- 电功率范围：2039.144-2042.332 W；
- 电功率均值：2040.657 W；
- 半极差/均值：0.0781%；
- 线性漂移：0.1557%；
- 末端电压：9.5524 V；
- TEC和水力计算均收敛，记录数据均为有限值。

窗口内关键部件最高温度为：芯块1869.58 K、接收极750.24 K、发射极
1687.92 K、慢化剂728.13 K、反射层717.37 K、冷却剂733.04 K。已给定的
芯块、接收极、慢化剂和反射层温度限值均未触发。

因此，该工作点满足2.0-2.2 kW目标和波动不超过+/-3%的要求。此结论只适用于
关闭外热流的固定工况，不等价于周期外热条件下的轨道周期稳态。
